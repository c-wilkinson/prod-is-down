# 📣 Nick O'Time — Incident Manager

**Nick O'Time**, the incident manager, joins and asks for three things:

1. Current impact.
2. Root cause.
3. ETA.

You reliably know only the first one.

Nick explains that stakeholders *"just need a rough time"*. From this point on, someone will ask for another ETA approximately four minutes after every ETA.
