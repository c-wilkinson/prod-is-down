# 🛡️ Mallory — Security

**Mallory from Security** has joined the incident.

This would be less ominous if everyone in cryptography textbooks had not spent decades teaching you what a Mallory does.

She notices that the DEBUG logs contain request metadata that normally is not written in production. There is no evidence of compromise, but leaving DEBUG enabled increases information exposure and retention.

Your availability incident is trying to collect a security subplot.
